# 部署到 GitHub Pages（免费版，10 分钟）

## 这个文件夹里有什么

| 文件 | 作用 |
|---|---|
| `index.html` | 应用本体（卡片全部内嵌在里面，单文件也能独立运行） |
| `manifest.webmanifest` | 让 iPhone / Android 能「添加到主屏幕」变成 App 图标 |
| `sw.js` | Service Worker：离线可用 + 有新版本时弹横幅提示 |
| `icon-*.png` | App 图标 |

## 一、建仓库并上传

1. 打开 https://github.com/new
2. Repository name 填 `anki`（随便什么名字都行）
3. 选 **Public**（免费版的 GitHub Pages 只支持公开仓库）
4. 点 **Create repository**
5. 在仓库页面点 **Add file → Upload files**，把这个文件夹里的**所有文件**拖进去（不要连文件夹一起拖，要拖文件本身）
6. 点 **Commit changes**

## 二、打开 Pages

1. 仓库页面 → **Settings** → 左侧 **Pages**
2. Source 选 **Deploy from a branch**
3. Branch 选 **main**，文件夹选 **/ (root)**，点 **Save**
4. 等 1〜2 分钟，页面顶部会出现网址：
   `https://你的用户名.github.io/anki/`

这个网址就是最终地址，发给朋友即可。

## 三、iPhone 上装成 App

1. 用 **Safari** 打开上面的网址（必须是 Safari，Chrome 不行）
2. 点底部的 **分享** 按钮 → **添加到主屏幕**
3. 主屏幕上会出现「暗記カード」图标，点开是全屏的，没有浏览器地址栏
4. 之后**没有网也能打开**（Service Worker 已经把内容缓存下来了）

Android 用 Chrome 打开，会自动弹「安装应用」。Mac 上 Chrome 地址栏右侧也有安装按钮。

## 四、以后怎么更新卡片

1. 在 `カード原稿/` 里改或加 TSV
2. 让我重新构建（或你自己跑 `python3 build.py`）
3. 把新的 `index.html` 和 `sw.js` 传到仓库覆盖（GitHub 网页上直接 Upload files 覆盖即可）
4. 所有人下次打开时，顶部会出现 **「新しいバージョンがあります → 今すぐ更新」** 横幅，点一下就是最新版

**重要：`sw.js` 一定要一起传。** 版本号写在里面，浏览器靠它判断有没有新版。
（build.py 每次会自动把版本号写成「日期 (张数)」，不用手动改。）

**学习进度不会丢。** 进度存在这个网址的域名下，跟 `index.html` 这个文件本身无关，
换多少次版本都不受影响。每个人的进度也是各自独立的。

## 五、几个注意点

- **免费版的限制**：站点 ≤ 1GB、每月 100GB 流量、每小时 10 次构建。这个应用几百 KB，完全用不完。
- **仓库是公开的**，卡片内容任何人都能看到，也可能被搜索引擎收录。如果不想公开，
  改用 Cloudflare Pages（免费版支持私有仓库），部署方式类似。
- **不要往仓库里放有版权的材料**（教材扫描件、过去问原文 PDF 等）。自己整理的笔记没问题。
- 进度是**按设备、按浏览器**存的。Mac 上的进度和 iPhone 上的进度是两套，
  要搬运的话用应用内的「💾 進捗バックアップ」导出 JSON，在另一台设备「📥 進捗を復元」。
