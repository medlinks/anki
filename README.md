# 予備試験 暗記カード

日语医学预备考试的间隔重复记忆卡（免疫学・解剖学・生化学・微生物学）。
纯静态单文件 Web App，支持 PWA 安装、离线使用、SM-2 间隔重复。

线上地址：<https://medlinks.github.io/anki/>

---

## 目录结构

```
cards/                    卡片原稿（这是唯一需要经常改的地方）
  免疫01_MHC抗原処理.tsv
  解剖01_脳神経.tsv
  ...
build/                    HTML 模板（很少动）
  part1_head.html         页面骨架 + 样式
  part2_script.html       应用逻辑
static/                   PWA 静态资源（几乎不动）
  manifest.webmanifest / sw.js / icon-*.png
build.py                  构建脚本：cards + build + static → dist/
.github/workflows/deploy.yml   推送后自动构建并发布
```

## 每次更新卡片：只需要 1 步

1. 打开 GitHub 仓库 → 进入 `cards/` 文件夹
2. **加新科目** → `Add file → Upload files`，把新的 `.tsv` 拖进去
   **改已有卡片** → 点开对应 `.tsv` → 铅笔图标 → 直接改 → `Commit changes`
3. 完事

推送后 GitHub Actions 会自动：
重新构建 → 版本号自动写成「日期 (张数)」→ 更新 `sw.js` → 发布到 Pages。
大约 1〜2 分钟后，所有人打开网页时顶部会出现
**「新しいバージョンがあります → 今すぐ更新」**，点一下就是最新版。

手机浏览器上也能完成这个操作。

## TSV 格式

制表符分隔的 5 列，**不要用逗号**：

```
デッキ名 ⇥ 表（問） ⇥ 裏（答） ⇥ メモ ⇥ タグ
```

示例：

```
解剖学::03 心臓	僧帽弁の位置と尖の数は？	左心房と左心室の間、2 尖弁（前尖・後尖）	2 尖なのは僧帽弁だけ	心臓,弁膜,頻出
```

规则：

- 牌组名用 `::` 分层，子牌组前面加 `01 ` `02 ` 控制显示顺序
- 第 4 列（メモ）和第 5 列（タグ）可以留空，但**制表符必须有**（必须正好 5 列）
- 不要出现 反引号 `` ` ``、`${`、反斜杠 `\` —— 会破坏内嵌的模板字符串，构建会直接失败

## 构建脚本会自动拦截的错误

推上去之后如果 Actions 变红，点进去看日志，通常是这三种之一：

| 报错 | 意思 | 怎么修 |
|---|---|---|
| `列数が5でない行があります` | 某行不是 5 列 | 按提示的行号补制表符 |
| `テンプレートリテラルを壊す文字` | 出现了 `` ` `` / `${` / `\` | 删掉或换成别的写法 |
| `ID衝突（科目＋表が重複）` | 同一科目下有两张卡正面文字完全一样 | 改其中一张的问法 |

Actions 红了的话，线上站点会保持上一个成功的版本，不会被弄坏。

## 学习进度为什么不会丢

卡片 ID = `hash(科目名 + 表的文言)`，**不包含子牌组名**。
所以以下操作都不会影响任何人的学习进度：

- 重新给子牌组编号（`01 脳神経` → `05 脳神経`）
- 改子牌组名字
- 调整 TSV 文件名、拆分或合并文件
- 发布任意多次新版本

只有**改动卡片正面的文字**才会被当成新卡（旧的那张会消失、新的从零开始）。
所以修改答案、备注、标签都很安全；要改问法的话，心里有数即可。

进度存在浏览器的 localStorage（按域名、按设备），每个人各自独立。
换设备用应用内的「💾 進捗バックアップ」导出 JSON，在另一台「📥 進捗を復元」。
